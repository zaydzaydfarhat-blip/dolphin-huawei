# Ported patches

This folder is reserved for small, reviewable changes ported from MMJR2-VBI into the Official Dolphin base.

Rules:
- Keep each port isolated and document its original upstream commit or pull request.
- Prefer current Official Dolphin implementations when the same feature already exists.
- Do not copy old Android input, graphics, or storage code wholesale.
- Build and test after each port; keep experimental Huawei/Maleoon changes separate until measured on-device.
- Do not describe a patch as a performance improvement without benchmark evidence.
